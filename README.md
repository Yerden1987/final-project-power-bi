# Итоговый проект по анализу данных — Power BI

## Описание проекта

В рамках итогового проекта разработан интерактивный аналитический отчёт в Microsoft Power BI для анализа продаж, прибыльности, логистики, клиентов и эффективности сотрудников.

Проект включает обработку данных, создание аналитических показателей с помощью DAX и разработку визуализаций для оценки бизнес-показателей.

## Используемые инструменты

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Визуализация данных
- Анализ ключевых показателей эффективности (KPI)

## Структура отчёта

Отчёт состоит из пяти аналитических страниц:

**1. Sales & Profit**

Анализ продаж, прибыли, рентабельности и динамики основных финансовых показателей.

**2. Logistics & Warehouses**

Анализ логистики, способов доставки и показателей складской деятельности.

**3. Customers & Regions**

Анализ клиентов, сегментов и географического распределения продаж.

**4. Employees & Performance**

Анализ эффективности сотрудников и показателей их работы.

**5. Insights & Recommendations**

Обобщение результатов анализа, выявление ключевых закономерностей и формирование рекомендаций для бизнеса.

## Основные задачи проекта

- Подготовка и преобразование данных в Power Query.
- Создание модели данных.
- Разработка DAX-мер для расчёта KPI.
- Построение интерактивных диаграмм и аналитических таблиц.
- Настройка фильтров для исследования данных.
- Формирование выводов и рекомендаций на основе полученных результатов.

## Файлы проекта

- `Final_Project_PowerBI.pbix` — интерактивный отчёт Power BI.
- `Final_Project_PowerBI.pdf` — PDF-версия аналитического отчёта.

## Результат

Разработан аналитический дашборд из пяти страниц, позволяющий исследовать ключевые бизнес-показатели, отслеживать динамику продаж и прибыли, анализировать работу логистики, клиентов и сотрудников.

Отчёт предназначен для поддержки принятия решений на основе данных.
